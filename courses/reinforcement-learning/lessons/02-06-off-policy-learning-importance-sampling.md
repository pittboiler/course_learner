# Reinforcement Learning · Lesson 2.6: Off-policy learning and importance sampling

> ⏱ ~15 min · Module 2: Model-Free Prediction & Control · Builds on: [2.5 (Q-learning)](02-05-q-learning-off-policy-td-control.md), [2.1 (Monte Carlo prediction)](02-01-monte-carlo-prediction.md) · Unlocks: [3.2 (control with approximation and the deadly triad)](03-02-approximate-control-deadly-triad.md), [4.3 (PPO)](04-03-ppo-a-taste.md)

## Why this matters

[Lesson 2.5](02-05-q-learning-off-policy-td-control.md) pulled off something that should look suspicious: it learned the value of the greedy policy from data generated by an $\varepsilon$-greedy one, with no correction of any kind. That worked because of a special feature of the one-step $\max$ target. In general, **learning about a policy you are not following requires paying for the mismatch**, and this lesson is about the currency.

The payment matters well beyond tidying up Q-learning's paperwork. Off-policy learning is what lets an agent learn from logged data, from a human demonstrator, from an old version of itself stored in a replay buffer ([Lesson 4.1](04-01-deep-q-networks.md)), or from many parallel workers running slightly stale policies ([Lesson 4.2](04-02-a2c-a3c-advantage-estimation.md)). And the importance ratio introduced here is *the* object in PPO's clipped objective ([Lesson 4.3](04-03-ppo-a-taste.md)) — the clipping exists precisely to control the variance this lesson diagnoses.

## The idea

You have samples drawn from $b$ and you want an expectation under $\pi$. Reweight.

$$\mathbb{E}_{a\sim\pi}[f(a)] = \sum_a \pi(a) f(a) = \sum_a b(a)\,\frac{\pi(a)}{b(a)}\,f(a) = \mathbb{E}_{a\sim b}\!\left[\frac{\pi(a)}{b(a)}\,f(a)\right]$$

In words: count each sample according to how much more (or less) likely the target policy would have been to produce it.

> An action that $\pi$ loves and $b$ rarely takes must count for many; an action $b$ takes constantly and $\pi$ avoids must count for little.

The identity is exact, and it is free of assumptions except one: **wherever $\pi$ puts probability, $b$ must too.** If $b(a) = 0$ while $\pi(a) > 0$, that action is never sampled and no reweighting can invent it. This is the **coverage** condition, and it is the same requirement as the *overlap* assumption in [`econometrics` 3.1](../../econometrics/lessons/03-01-potential-outcomes-identification.md).

The trouble is that a return depends on a *whole trajectory*, so the correction is a **product** of per-step ratios — and products of random factors are where variance goes to die.

## The formal version

**The trajectory ratio.** For the segment from $t$ to termination at $T$:

$$\rho_{t:T-1} = \prod_{k=t}^{T-1}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}$$

In words: multiply the per-step likelihood ratios along everything that happened. Note the transition probabilities $p(s'\mid s,a)$ appear in both numerator and denominator and **cancel exactly** — so the ratio is computable without a model, which is the only reason any of this is usable. *(card: [importance sampling ratio](../reference.md#importance-sampling-ratio))*

**Two estimators.** Given returns $G_t$ observed under $b$ across a set of visits $\mathcal{T}$ to state $s$:

$$\underbrace{V(s) = \frac{\sum_{t\in\mathcal{T}}\rho_{t:T-1}\,G_t}{|\mathcal{T}|}}_{\textbf{ordinary}} \qquad\qquad \underbrace{V(s) = \frac{\sum_{t\in\mathcal{T}}\rho_{t:T-1}\,G_t}{\sum_{t\in\mathcal{T}}\rho_{t:T-1}}}_{\textbf{weighted}}$$

They differ only in the denominator, and that one change flips every property:

| | ordinary IS | weighted IS |
|---|---|---|
| bias | **unbiased** | biased (vanishes as $n$ grows) |
| variance | can be **infinite** | bounded — the estimate can never exceed the largest observed return |
| in practice | rarely usable alone | the default |

The weighted estimator's boundedness is easy to see: it is a convex combination of the observed $G_t$, so it lies inside their range no matter how wild the weights get. The ordinary estimator has no such protection — one enormous $\rho$ can throw it anywhere.

**Why Q-learning needed none of this.** The correction fixes a mismatch in *which action was sampled at the next state*. Q-learning's target, $R_{t+1} + \gamma\max_a Q(S_{t+1},a)$, samples no action at $S_{t+1}$ — it maximizes over all of them. There is nothing to reweight. Two caveats worth keeping: this is a property of the **one-step** target (an $n$-step off-policy return does need correcting for the intermediate actions), and the mismatch in **which states get visited** still exists, which is why Q-learning still requires every pair to be visited infinitely often.

**The variance mechanism, exactly.** Let $b$ be $\varepsilon$-greedy with $\varepsilon = 0.1$ over two actions, so $b(\text{greedy}) = 0.95$, and let $\pi$ be the deterministic greedy policy. Then every per-step ratio is $1/0.95$ if the greedy action was taken, and $0$ otherwise. Over $T$ steps:

$$\rho_{0:T-1} = \begin{cases}(1/0.95)^T & \text{with probability } 0.95^T\\ 0 & \text{otherwise}\end{cases}$$

The product of those two numbers is exactly $1$, which is the unbiasedness. But the second moment is $0.95^T \cdot (1/0.95)^{2T} = (1/0.95)^T$, so

$$\operatorname{Var}[\rho] = (1/0.95)^T - 1,$$

which grows **exponentially in the trajectory length**:

| $T$ | chance the weight is nonzero | the weight, when nonzero | $\operatorname{Var}[\rho]$ |
|---|---|---|---|
| $10$ | $0.599$ | $1.67$ | $0.67$ |
| $50$ | $0.077$ | $13.0$ | $12.0$ |
| $100$ | $0.0059$ | $168.9$ | $167.9$ |
| $200$ | $0.00004$ | $28{,}529$ | $28{,}528$ |

At $T = 100$, **fewer than six episodes in a thousand contribute anything at all, and each of those counts for $169$ episodes.** The estimator is unbiased and effectively informationless. This is why off-policy Monte Carlo over long episodes is close to hopeless, and why bootstrapping methods — which correct only one step at a time — dominate in practice.

## Worked examples

**Example 1 (mechanical): computing a trajectory ratio.** A three-step episode in which the target policy $\pi$ is deterministic and the behaviour policy $b$ is $\varepsilon$-greedy with $\varepsilon = 0.2$ over three actions — so $b(\text{greedy}) = 1 - 0.2 + 0.2/3 = 0.8667$ and $b(\text{other}) = 0.0667$.

Suppose the agent took $\pi$'s preferred action at steps $0$ and $1$, and an exploratory action at step $2$. Then

$$\rho_{0:2} = \frac{1}{0.8667}\cdot\frac{1}{0.8667}\cdot\frac{0}{0.0667} = \mathbf{0}.$$

**One off-policy action kills the entire trajectory.** The return is discarded — correctly, since $\pi$ would never have produced that trajectory, so it says nothing about $\pi$'s value.

Had all three been on-policy, $\rho_{0:2} = (1/0.8667)^3 = 1.535$, and the return would count for half again as much as it appears. The arithmetic shows both faces of importance sampling at once: it throws away most of the data and inflates what remains.

**Example 2 (why you'd care): unbiased and useless.** A single state $s$ with two actions. Action *left* returns to $s$ with reward $0$ with probability $0.9$, and terminates with reward $+1$ with probability $0.1$. Action *right* terminates immediately with reward $0$.

The target policy $\pi$ always chooses *left*. Under it the episode terminates with probability $1$ and **always with a reward of $+1$**, so

$$V^\pi(s) = 1.$$

The behaviour policy $b$ is uniform, choosing each action with probability $\tfrac12$, so every per-step ratio is $1/0.5 = 2$ for *left* and $0$ for *right*.

*Is the estimator unbiased?* An episode contributing a nonzero weight must consist of $k$ self-loops and then a terminating *left*, which under $b$ has probability $(0.5 \times 0.9)^k(0.5\times 0.1) = 0.45^k(0.05)$, carries $\rho = 2^{k+1}$, and returns $G = 1$. So

$$\mathbb{E}_b[\rho G] = \sum_{k\ge0} 0.45^k(0.05)\,2^{k+1} = 0.1\sum_{k\ge0}(0.9)^k = 0.1\cdot\frac{1}{0.1} = \mathbf{1}\ \checkmark$$

*Is it usable?* The second moment is

$$\mathbb{E}_b[(\rho G)^2] = \sum_{k\ge0}0.45^k(0.05)\,4^{k+1} = 0.2\sum_{k\ge0}(1.8)^k = \boldsymbol{\infty},$$

because the ratio of consecutive terms is $0.45\times4 = 1.8 > 1$. **The variance is infinite.** The partial sums make it concrete: truncating at $k<10$ gives $89$, at $k<20$ gives $31{,}870$, at $k<40$ gives $4\times10^9$.

What that looks like in a run. Six independent runs of $100{,}000$ episodes each, estimating a quantity whose true value is $1$:

| after | ordinary IS, across six runs |
|---|---|
| $100$ episodes | $0.26,\ 0.34,\ 1.60,\ 0.90,\ 0.82,\ 0.58$ |
| $10{,}000$ | $0.63,\ 0.55,\ 0.72,\ 0.88,\ 0.81,\ 0.60$ |
| $100{,}000$ | $0.66,\ 0.64,\ 0.89,\ 0.71,\ 0.89,\ 0.68$ |

**A hundred thousand episodes and the estimates are still scattered between $0.64$ and $0.89$, with no sign of settling.** With infinite variance the law of large numbers still applies — the estimator converges eventually — but the central limit theorem does not, so there is no $1/\sqrt{n}$ rate and no usable error bar.

Weighted importance sampling returns exactly $1.000$ in all six runs from the first nonzero-weight episode onward. (That exactness is special to this example: every episode with nonzero weight has $G = 1$, so the convex combination is trivially $1$. The general guarantee is only boundedness — but boundedness is the entire difference between an estimator you can use and one you cannot.)

## Watch out

- **You might think** unbiasedness is the property to optimize for — **but actually** an unbiased estimator with infinite variance is worthless, and a slightly biased bounded one is not. Example 2 is the demonstration: ordinary IS is exactly right on average and wrong in every individual run; weighted IS is provably biased and exactly right in every run. Mean squared error, not bias, is what matters.
- **You might think** a zero importance weight means the sample was corrupted — **but actually** it means the target policy would never have produced that trajectory, so discarding it is correct. The problem is not that zeros are wrong; it is that there are so many of them that almost no data survives, which is a *statistical efficiency* failure rather than a correctness one.
- **You might think** the coverage condition ($b(a\mid s) > 0$ wherever $\pi(a\mid s) > 0$) is a technicality — **but actually** it is the thing that fails silently in practice. Learning from a logged dataset in which some action was never taken in some state gives you no information about that action, and an algorithm that does not check will happily extrapolate a value for it. This is the central difficulty of offline RL, and it is the same failure as [Lesson 1.1](01-01-the-rl-problem.md)'s "policy-dependent data" seen from the other end.

## One-liner

> You can learn about a policy you are not following by reweighting each trajectory by how likely it was under each — but the weight is a product along the trajectory, so it is usually either zero or enormous.

## Problems

**P1 (🟢)** A target policy $\pi$ takes action $a_1$ with probability $0.8$ and $a_2$ with probability $0.2$. The behaviour policy $b$ is uniform over the two actions.

(a) Compute the per-step ratio for each action.
(b) A two-step trajectory took $a_1$ then $a_2$. Compute $\rho_{0:1}$.
(c) A two-step trajectory took $a_1$ twice. Compute $\rho_{0:1}$.
(d) Verify that $\mathbb{E}_b[\rho]$ over a single step equals $1$.

**P2 (🟡)** Behaviour is $\varepsilon$-greedy with $\varepsilon = 0.2$ over four actions; the target is the deterministic greedy policy.

(a) Compute $b(\text{greedy}\mid s)$ and the per-step ratio when the greedy action is taken.
(b) Compute the probability that a $20$-step trajectory has a nonzero weight, and the weight in that case.
(c) Compute the variance of $\rho_{0:19}$.
(d) State the length $T$ at which fewer than one trajectory in a hundred survives, and comment on what that means for off-policy Monte Carlo on episodes of realistic length.

**P3 (🔴)** An engineer wants an off-policy **$n$-step** return, arguing that since Q-learning needs no importance sampling, neither should its $n$-step version.

(a) Write the $2$-step Q-learning-style target $R_{t+1} + \gamma R_{t+2} + \gamma^2\max_a Q(S_{t+2},a)$ and identify which actions in it were sampled from the behaviour policy.
(b) State which of those need correcting and which do not, with the reason for each.
(c) Give the importance ratio that corrects the $2$-step target.
(d) **Tree backup** is an alternative that achieves an off-policy $n$-step target with *no* importance sampling, by replacing each sampled intermediate action's contribution with an expectation over the target policy. Explain in two sentences why this removes the need for a correction, and state the cost.

<details>
<summary>Solutions</summary>

**P1**

(a) $\dfrac{\pi(a_1)}{b(a_1)} = \dfrac{0.8}{0.5} = \mathbf{1.6}$ and $\dfrac{\pi(a_2)}{b(a_2)} = \dfrac{0.2}{0.5} = \mathbf{0.4}$.

(b) $\rho_{0:1} = 1.6 \times 0.4 = \mathbf{0.64}$.

(c) $\rho_{0:1} = 1.6 \times 1.6 = \mathbf{2.56}$.

(d) Under $b$, each action has probability $0.5$:

$$\mathbb{E}_b[\rho] = 0.5(1.6) + 0.5(0.4) = 0.8 + 0.2 = \mathbf{1}\ \checkmark$$

This is always true — $\mathbb{E}_b[\pi/b] = \sum_a b(a)\pi(a)/b(a) = \sum_a \pi(a) = 1$ — and it is the one-line reason ordinary importance sampling is unbiased.

**P2**

(a) $b(\text{greedy}\mid s) = 1 - \varepsilon + \varepsilon/|\mathcal{A}| = 1 - 0.2 + 0.05 = \mathbf{0.85}$, so the ratio is $1/0.85 \approx \mathbf{1.176}$.

(b) $\mathbb{P}[\text{nonzero}] = 0.85^{20} = \mathbf{0.0388}$ — under four percent. The weight in that case is

$$(1/0.85)^{20} = \frac{1}{0.0388} \approx \mathbf{25.8}.$$

(Their product is $1$, as it must be.)

(c) $\mathbb{E}[\rho^2] = 0.85^{20}(1/0.85)^{40} = (1/0.85)^{20} = 25.8$, so

$$\operatorname{Var}[\rho] = 25.8 - 1 = \mathbf{24.8}.$$

A standard deviation of about $5$ on a quantity whose mean is $1$.

(d) Solve $0.85^T < 0.01$: $T > \dfrac{\ln 0.01}{\ln 0.85} = \dfrac{-4.605}{-0.1625} = 28.3$, so $T = \mathbf{29}$.

**Twenty-nine steps is nothing.** An Atari episode runs to thousands of frames; a robotics episode to hundreds of control steps. So for any realistic episode length, off-policy Monte Carlo with a deterministic target and an $\varepsilon$-greedy behaviour policy discards essentially all its data, and the handful of surviving trajectories carry astronomical weights. **This is the practical death of trajectory-level importance sampling**, and it is why methods that correct one step at a time — Q-learning, tree backup, or PPO's clipped single-step ratio — are what actually get used.

**P3**

(a) The target is $R_{t+1} + \gamma R_{t+2} + \gamma^2\max_a Q(S_{t+2},a)$. Two actions were sampled from $b$ along the way:

- $A_t$, the action whose value is being updated;
- $A_{t+1}$, the action taken at $S_{t+1}$, which determined $R_{t+2}$ and $S_{t+2}$.

At $S_{t+2}$ no action is sampled — the $\max$ covers all of them.

(b) **$A_t$ needs no correction.** It is the action the update is *about*: we are estimating $Q(S_t,A_t)$, so conditioning on it is the point, not a mismatch. This is why one-step Q-learning is correction-free.

**$A_{t+1}$ does need correcting.** The target policy is greedy, and $b$ may well have taken an exploratory action at $S_{t+1}$. The reward $R_{t+2}$ and the state $S_{t+2}$ are consequences of *that* choice, so they describe a continuation $\pi$ would not have made. Without a correction the $2$-step target estimates a blend of $\pi$ and $b$.

**$S_{t+2}$'s action needs no correction**, for the same reason as in one-step Q-learning: it is maximized over rather than sampled.

(c) Only the single intermediate action needs fixing:

$$\rho_{t+1} = \frac{\pi(A_{t+1}\mid S_{t+1})}{b(A_{t+1}\mid S_{t+1})},$$

and the corrected target is $R_{t+1} + \gamma\rho_{t+1}\big[R_{t+2} + \gamma\max_a Q(S_{t+2},a)\big]$, the ratio multiplying everything that came *after* the action it corrects. With a deterministic greedy $\pi$ this is $1/b(A_{t+1}\mid S_{t+1})$ when $b$ happened to act greedily and $\mathbf{0}$ otherwise — so an exploratory step at $t+1$ truncates the target back to the one-step case.

(d) Tree backup replaces the sampled action's contribution at each intermediate state with $\sum_a \pi(a\mid S_{t+k})Q(S_{t+k},a)$ — an expectation under the *target* policy over all actions — while using the sampled trajectory only to decide how deep to recurse. Since no intermediate action is ever sampled-and-used, there is no distributional mismatch to correct and no ratio appears.

**The cost is that the target leans on the current $Q$ estimates for every action not taken**, so it is more heavily bootstrapped and therefore more biased when those estimates are poor — and it needs $\pi$'s probabilities and a $Q$ value for every action at every step, which is $|\mathcal{A}|$ times the work per step. It trades importance sampling's variance for bootstrapping's bias, which is [Lesson 2.3](02-03-temporal-difference-learning-td0.md)'s trade-off appearing in yet another place.

</details>

## Flashback

**From Lesson 2.5 (Q-learning):** An agent runs Q-learning with $\gamma = 0.5$, $\alpha = 1$ (so each update replaces the estimate with the target outright), all $Q$ initialized to $0$, on this episode, repeated until nothing changes:

$$(p, \text{go}, R{=}2, q), \qquad (q, \text{up}, R{=}0, \text{terminal}), \qquad Q(q,\text{down}) \text{ is never updated from } 0.$$

Suppose a *different* episode sometimes occurs: $(q, \text{down}, R{=}6, \text{terminal})$.

(a) After both episode types have been seen many times, give $Q(q,\text{up})$ and $Q(q,\text{down})$.
(b) Give $Q(p,\text{go})$ under Q-learning.
(c) Give what SARSA would converge to for $Q(p,\text{go})$ if the behaviour policy chooses *up* and *down* with probability $\tfrac12$ each at $q$.
(d) Explain the difference in one sentence, and state which is $Q^*$.

<details>
<summary>Solution</summary>

(a) Both actions at $q$ terminate the episode, so their targets are just their rewards:

$$Q(q,\text{up}) = 0 + 0.5(0) = \mathbf{0}, \qquad Q(q,\text{down}) = 6 + 0.5(0) = \mathbf{6}.$$

(b) Q-learning's target for $(p,\text{go})$ uses the maximum at $q$:

$$Q(p,\text{go}) = 2 + 0.5\max\{0,\ 6\} = 2 + 3 = \mathbf{5}.$$

(c) SARSA bootstraps from the action actually taken, which is *up* or *down* with probability $\tfrac12$ each. Its fixed point is the expectation of the target:

$$Q(p,\text{go}) = 2 + 0.5\big[\tfrac12(0) + \tfrac12(6)\big] = 2 + 0.5(3) = \mathbf{3.5}.$$

(d) Q-learning values $(p,\text{go})$ at what it would be worth **if the agent went on to play well** at $q$; SARSA values it at what it is worth **given the agent will actually flip a coin** there — and Q-learning's $5$ is $Q^*(p,\text{go})$, since the optimal continuation from $q$ is *down*.

Worth connecting to this lesson: SARSA reached its answer with no importance sampling, and so did Q-learning — but they answered *different questions*. If you wanted $Q^*$ and only had SARSA's coin-flipping data, importance sampling is what would convert $3.5$ into $5$, by upweighting the *down* episodes by $\pi(\text{down})/b(\text{down}) = 1/0.5 = 2$ and downweighting the *up* ones to zero. **Q-learning's $\max$ performs that reweighting implicitly and exactly, which is precisely the shortcut this lesson explains.**

</details>
