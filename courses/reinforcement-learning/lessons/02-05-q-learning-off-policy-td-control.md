# Reinforcement Learning · Lesson 2.5: Q-learning — off-policy TD control

> ⏱ ~15 min · Module 2: Model-Free Prediction & Control · Builds on: [2.4 (SARSA)](02-04-sarsa-on-policy-td-control.md), [1.4 (optimality and the Bellman optimality equation)](01-04-optimality-bellman-optimality.md) · Unlocks: [2.6 (off-policy learning and importance sampling)](02-06-off-policy-learning-importance-sampling.md), [4.1 (deep Q-networks)](04-01-deep-q-networks.md)

## Why this matters

SARSA learns the value of the policy it is running. That is honest, and it is limiting: the policy it is running is deliberately suboptimal, because it explores. [Lesson 2.4](02-04-sarsa-on-policy-td-control.md) showed the consequence — with $\varepsilon$ fixed, SARSA converges to the best $\varepsilon$-soft policy and no further.

Q-learning breaks that link. It behaves one way and learns about another, converging to $Q^*$ — the optimal action-values — **while following an exploratory policy the whole time**. It was the result that made model-free RL look practical, and it is the algorithm inside DQN, which is [Lesson 4.1](04-01-deep-q-networks.md).

The change is one symbol. What it costs is a real behavioural difference that is easiest to see, and impossible to forget, on a cliff.

## The idea

SARSA bootstraps from $Q(S_{t+1}, A_{t+1})$ — the action it will actually take. Q-learning bootstraps from $\max_a Q(S_{t+1},a)$ — the best action available, whether or not the agent takes it.

$$\underbrace{R_{t+1} + \gamma\,Q(S_{t+1},A_{t+1})}_{\text{SARSA}} \qquad\longrightarrow\qquad \underbrace{R_{t+1} + \gamma\max_a Q(S_{t+1},a)}_{\text{Q-learning}}$$

The target no longer mentions the agent's own behaviour. So the agent may explore, act randomly, follow a human demonstrator, or replay data recorded years ago — and the thing being learned is the same either way.

> Q-learning asks "what would this be worth if I played perfectly from here?" while doing something else entirely.

Two policies are now in play, and keeping them apart is the whole vocabulary of off-policy learning:

- the **behaviour policy** $b$, which chooses the actions (here, $\varepsilon$-greedy);
- the **target policy** $\pi$, which is being evaluated (here, the greedy policy).

This separation is what makes the **cost of exploration invisible to the learner** — and therefore makes it a genuine cost, paid in the real world and never accounted for. The cliff is where that bill comes due.

## The formal version

**The update.**

$$Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma\max_a Q(S_{t+1},a) - Q(S_t,A_t)\big]$$

*(card: [Q-learning](../reference.md#q-learning))*

**It is the Bellman optimality equation, sampled.** Compare [Lesson 1.4](01-04-optimality-bellman-optimality.md):

$$Q^*(s,a) = r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q^*(s',a')$$

Q-learning replaces the sum over $s'$ with the single observed $S_{t+1}$ and $Q^*$ with the current estimate. **SARSA is the sampled Bellman *expectation* equation; Q-learning is the sampled Bellman *optimality* equation** — the same distinction as [Lesson 1.5](01-05-policy-evaluation-and-policy-iteration.md) versus [Lesson 1.6](01-06-value-iteration-and-convergence.md), reappearing one level down.

**Convergence.** Q-learning converges to $Q^*$ with probability $1$ given only:

1. every state–action pair is visited infinitely often;
2. the Robbins–Monro step-size conditions.

**Notice what is missing: no GLIE requirement.** SARSA needed the behaviour policy to become greedy in the limit; Q-learning does not, because its target never referred to the behaviour policy in the first place. Any behaviour policy that keeps trying everything will do. That is a strikingly weak condition, and it is why Q-learning is the default for learning from logged or demonstrated data.

**Why no importance sampling?** [Lesson 2.6](02-06-off-policy-learning-importance-sampling.md) shows that learning about $\pi$ from data generated by $b$ normally requires reweighting samples by $\pi(a\mid s)/b(a\mid s)$, often with brutal variance. Q-learning escapes this entirely, and the reason is worth stating precisely: the correction is needed to fix a mismatch in **which action is taken at the next state**, and Q-learning's target does not sample that action — it maximizes over all of them. There is no sampled choice to correct. (The mismatch in *which states get visited* remains, which is why condition 1 is still needed.)

**The maximization bias.** The $\max$ is not free. Because $\mathbb{E}[\max_a X_a] \ge \max_a \mathbb{E}[X_a]$ — Jensen's inequality for the convex $\max$ — taking a maximum over *noisy* estimates systematically overestimates. If several actions have the same true value, the one that happens to have been overestimated wins the $\max$, and its error is propagated as though it were signal. Q-learning is therefore **optimistically biased**, and the bias is worst when action-values are close and samples are few. [Lesson 4.1](04-01-deep-q-networks.md)'s Double DQN is the standard repair, and it works by using one estimate to *select* the maximizing action and a different one to *evaluate* it.

## Worked examples

**Example 1 (mechanical): the two updates on one episode.** Take this module's boss problem: $\alpha = 0.5$, $\gamma = 1$, all $Q$ initialized to $0$, and the episode

$$(s_1, \text{right}, R{=}{-}1, s_2), \qquad (s_2, \text{right}, R{=}{+}10, \text{terminal}).$$

**Q-learning, update 1.** The target is $-1 + 1\cdot\max_a Q(s_2,a) = -1 + 0 = -1$, so

$$Q(s_1,\text{right}) \leftarrow 0 + 0.5(-1 - 0) = \mathbf{-0.5}.$$

**Q-learning, update 2.** $s_2$'s successor is terminal, so the target is $10 + 0 = 10$:

$$Q(s_2,\text{right}) \leftarrow 0 + 0.5(10 - 0) = \mathbf{5}.$$

**Now SARSA on the first update**, supposing the agent's chosen next action was *left* with $Q(s_2,\text{left}) = 0$. Its target is

$$-1 + 1\cdot Q(s_2,\text{left}) = -1 + 0 = -1.$$

**The two targets are identical.** That is worth pausing on, because the expected answer is that they differ. At initialization every $Q$ is $0$, so $\max_a Q(s_2,a) = 0 = Q(s_2,\text{left})$ and the $\max$ has nothing to choose between. **The algorithms diverge only once the action-values at the next state actually differ** — after update 2, $Q(s_2,\text{right}) = 5$ while $Q(s_2,\text{left}) = 0$, and a second pass would give Q-learning the target $-1 + 5 = 4$ against SARSA's $-1 + 0 = -1$ whenever exploration picks *left*.

Which is exactly the cliff mechanism in miniature: **Q-learning credits $s_1$ with the good outcome that is available from $s_2$; SARSA credits it with the outcome the agent will actually stumble into.**

**Example 2 (why you'd care): the cliff.** A $4\times12$ grid. Start at the bottom-left, goal at the bottom-right, and the ten cells between them are a cliff: stepping into one costs $-100$ and teleports the agent back to the start. Every other step costs $-1$, $\gamma = 1$. Both agents use $\varepsilon$-greedy with $\varepsilon = 0.1$ and $\alpha = 0.5$.

The shortest route hugs the cliff edge: up one, across eleven, down one — **13 steps**. Over 80 runs of 500 episodes:

| | greedy policy learned | reward per episode while learning |
|---|---|---|
| **Q-learning** | the 13-step edge route (80/80 runs) | $\mathbf{-49.9}$ |
| **SARSA** | a 17-step route along the top row (79/80 runs) | $\mathbf{-27.0}$ |

**Q-learning found the better policy and collected roughly twice the penalty.**

The explanation is exact, and worth computing rather than hand-waving. Evaluate each route *as actually executed*, i.e. under the $\varepsilon$-greedy policy that keeps a $2.5\%$ chance per step of a downward slip:

| policy | value from the start |
|---|---|
| the 13-step edge route, executed with $\varepsilon = 0.1$ | $-51.81$ |
| the 15-step route one row back, with $\varepsilon = 0.1$ | $-21.05$ |
| the 17-step top-row route, with $\varepsilon = 0.1$ | $-22.27$ |
| **the best policy given $\varepsilon = 0.1$** | $\mathbf{-20.71}$ |
| the 13-step route executed with no exploration at all | $\mathbf{-13}$ |

Everything follows from this table. Q-learning learned the policy worth $-13$ *if executed perfectly*, and earned $-49.9$ — almost exactly the $-51.81$ that policy is worth when executed with $\varepsilon = 0.1$. SARSA aimed at the best $\varepsilon$-soft policy, worth $-20.71$, and earned $-27.0$ (still improving). Neither algorithm is malfunctioning: **they are optimizing different objectives, and each achieves its own.**

Note that the top row is not even the best safe route — one row back is worth $-21.05$ against the top row's $-22.27$. SARSA usually settles on the top row because those two differ by barely one unit, well inside the noise of a constant-$\alpha$ run. It reliably learns "get away from the cliff"; it does not reliably fine-tune how far.

**The practical reading.** If exploration will be switched off at deployment, Q-learning is right and the $-49.9$ was a training expense. If the agent will keep exploring in the field — or if the environment is a real machine where falling off cliffs is not reversible — SARSA is optimizing the quantity you actually care about. Decaying $\varepsilon$ makes the two agree in the limit, which is why it is the standard resolution.

## Watch out

- **You might think** Q-learning is strictly better than SARSA because it converges to $Q^*$ — **but actually** it converges to the values of a policy the agent is not running, and during learning it performs worse whenever exploration is dangerous. "Converges to the optimal values" and "behaves well" are different guarantees, and the cliff separates them by a factor of two.
- **You might think** the $\max$ in the target is just a notational convenience for "the greedy action" — **but actually** it introduces a systematic upward bias, because a maximum over noisy estimates exceeds the maximum of their means. With few samples and closely-valued actions this can be large, and it is a real cause of instability in deep RL. [Lesson 4.1](04-01-deep-q-networks.md)'s double estimator is the fix.
- **You might think** Q-learning's freedom from importance sampling means off-policy learning is free in general — **but actually** it is a special property of the one-step $\max$ target. The moment you want $n$-step returns ([Lesson 2.7](02-07-n-step-returns-and-the-lambda-return.md)) or to evaluate a *stochastic* target policy, the sampled actions along the way do need correcting, and [Lesson 2.6](02-06-off-policy-learning-importance-sampling.md)'s machinery — with its variance problems — comes back.

## One-liner

> Bootstrap from the best action rather than the one you took, and you learn the optimal values while behaving however you like — at the price of never noticing what your own exploration costs.

## Problems

**P1 (🟢)** An agent in state $s$ takes action $a$, gets $R = 1$, and lands in $s'$ where $Q(s',a_1) = 4$, $Q(s',a_2) = 7$, $Q(s',a_3) = 2$. Currently $Q(s,a) = 3$, with $\gamma = 0.9$ and $\alpha = 0.2$.

(a) Compute the Q-learning target and the updated $Q(s,a)$.
(b) The exploratory action actually taken at $s'$ was $a_3$. Compute the SARSA target and the updated $Q(s,a)$.
(c) State the difference between the two updates and which is larger.
(d) State the condition on the $Q$-values at $s'$ under which the two updates would coincide.

**P2 (🟡)** In the cliff task, consider the cell immediately above the cliff, one column from the goal. Under $\varepsilon$-greedy with $\varepsilon = 0.1$ and four actions, the agent's intended action is *right*.

(a) Compute the probability that the agent moves *down* (into the cliff) on this step.
(b) Over the eleven cells along the edge route, compute the probability of at least one fall in a single traversal, assuming independence and the same per-cell risk.
(c) Using $-100$ per fall, estimate the expected penalty per traversal from falls alone, and compare it with the $13$-step route's base cost.
(d) Your estimate in (c) should be compared with the exact figure of $-51.81$ quoted in Example 2. State one reason the simple estimate is not exact.

**P3 (🔴)** Maximization bias. A state $s'$ has $10$ actions whose **true** values are all exactly $0$. The agent's estimates $Q(s',a)$ are independent, each $\mathcal{N}(0,1)$.

(a) State the value that an unbiased target would use for $\max_a Q^*(s',a)$.
(b) The expected maximum of $n$ independent standard normals is approximately $\sqrt{2\ln n}$ for moderate $n$. Compute the approximate value of $\mathbb{E}[\max_a Q(s',a)]$ for $n = 10$ and state the resulting bias.
(c) Explain why this bias does not vanish merely by collecting more data at $s'$ in the way an ordinary estimation error would, and state what does reduce it.
(d) **Double Q-learning** keeps two independent tables $Q_A$ and $Q_B$, and uses the target $R + \gamma\, Q_B\big(s', \arg\max_a Q_A(s',a)\big)$. Explain why this is unbiased in the setting of (a), and identify the assumption the argument needs.

<details>
<summary>Solutions</summary>

**P1**

(a) $\max_a Q(s',a) = 7$, so the target is $1 + 0.9(7) = 1 + 6.3 = \mathbf{7.3}$ and

$$Q(s,a) \leftarrow 3 + 0.2(7.3 - 3) = 3 + 0.2(4.3) = \mathbf{3.86}.$$

(b) SARSA bootstraps from $Q(s',a_3) = 2$: target $= 1 + 0.9(2) = \mathbf{2.8}$, so

$$Q(s,a) \leftarrow 3 + 0.2(2.8 - 3) = 3 - 0.04 = \mathbf{2.96}.$$

(c) Q-learning **increased** $Q(s,a)$ from $3$ to $3.86$; SARSA **decreased** it to $2.96$. The targets differ by $7.3 - 2.8 = 4.5$, and Q-learning's is larger.

The two updates point in opposite directions on identical experience, which is the whole lesson: Q-learning reads the transition as "this action leads somewhere worth $7$", SARSA as "this action led somewhere from which I then did something worth $2$."

(d) They coincide exactly when the action actually taken at $s'$ is a maximizing one — $Q(s',A_{t+1}) = \max_a Q(s',a)$. That happens whenever exploration does not fire (probability $1-\varepsilon$ of taking the greedy action) and, trivially, whenever all the action-values at $s'$ are equal, which is why Example 1's two targets agreed at initialization.

**P2**

(a) $\varepsilon$-greedy with $\varepsilon = 0.1$ over four actions takes a uniformly random action with probability $0.1$, and *down* is one of the four:

$$\mathbb{P}[\text{down}] = 0.1 \times \tfrac14 = \mathbf{0.025}.$$

(b) With eleven independent cells each carrying risk $0.025$:

$$1 - (1 - 0.025)^{11} = 1 - 0.975^{11} = 1 - 0.7569 = \mathbf{0.243},$$

so roughly a **one-in-four** chance of falling at least once per traversal.

(c) The expected number of falls per traversal is $11 \times 0.025 = 0.275$, so the expected penalty from falls is

$$0.275 \times (-100) = \mathbf{-27.5},$$

against a base cost of $-13$ for the steps themselves — giving a rough total of about $-40.5$. **The hazard costs more than twice the journey.**

(d) *Accept criterion: any correct mechanism by which the simple estimate understates the true cost.*

The main reason: **a fall returns the agent to the start, so it must walk the whole gauntlet again** — and may fall again. The simple estimate counts each fall once at $-100$ and ignores the repeated traversals it forces, so it undercounts both the extra step costs and the extra fall risk. A geometric correction for the restarts pushes the figure from about $-40$ toward the exact $-51.81$.

Two smaller effects: exploration also causes non-fatal detours (random *left* and *up* moves) that add steps, and the exact calculation evaluates the $\varepsilon$-greedy policy over the whole grid rather than an idealized straight line, so the agent sometimes finds itself off-route entirely.

**P3**

(a) All true values are $0$, so $\max_a Q^*(s',a) = \mathbf{0}$. An unbiased target would use $R + \gamma(0) = R$.

(b) With $n = 10$: $\sqrt{2\ln 10} = \sqrt{2(2.3026)} = \sqrt{4.6052} \approx \mathbf{2.15}$.

So $\mathbb{E}[\max_a Q(s',a)] \approx 2.15$ while the truth is $0$: a bias of about $+2.15$ standard deviations, **entirely manufactured from noise**. (The approximation overstates slightly — the exact expected maximum of ten standard normals is about $1.54$ — but the direction and order of magnitude are right, and the point is that it is large and positive.)

(c) Because the bias comes from the $\max$ operation, not from the individual estimates being poor. More data at $s'$ shrinks each estimate's variance, which does shrink the bias — but at every sample size the $\max$ of the noisy estimates still exceeds the $\max$ of their means, so the target is *always* too high, and the error is systematic rather than averaging out across updates. An ordinary estimation error would cancel over many updates; this one accumulates, and worse, it propagates backwards through bootstrapping into the predecessors of $s'$.

What does reduce it: fewer actions to maximize over, genuinely separated action-values (the bias is largest when values are tied), lower-variance estimates — and, decisively, **decoupling the selection of the maximizing action from its evaluation**, which is (d).

(d) Write $a^* = \arg\max_a Q_A(s',a)$. Because $Q_A$ and $Q_B$ are **independent**, $a^*$ is a function of $Q_A$ alone and therefore independent of $Q_B$. Conditioning on $a^*$,

$$\mathbb{E}\big[Q_B(s',a^*)\big] = \mathbb{E}\Big[\mathbb{E}\big[Q_B(s',a^*)\ \big|\ a^*\big]\Big] = \mathbb{E}\big[Q^*(s',a^*)\big] = 0,$$

since $Q_B$ is an unbiased estimate of the true value of whatever action it is asked about, and here every true value is $0$. **The selection may be corrupted by noise, but the evaluation is not corrupted by the same noise**, so the upward bias disappears.

The assumption the argument needs is precisely that **independence**: $Q_B$ must not have been trained on the samples that shaped $Q_A$'s ordering. Double Q-learning enforces it by flipping a coin each step to decide which table is updated, so each is fitted to a disjoint half of the experience. Where that independence is only approximate — as in Double DQN, which reuses the target network rather than a genuinely separate estimator — the correction is partial rather than exact, and in practice still a large improvement.

</details>

## Flashback

**From Lesson 2.4 (SARSA):** An agent runs SARSA with $\gamma = 1$, $\alpha = 0.5$, all $Q$ initialized to $0$, on this episode, twice in succession:

$$(u, \text{go}, R{=}0, v),\qquad (v, \text{go}, R{=}4, \text{terminal}).$$

Assume *go* is selected at $v$ both times.

(a) Give $Q(u,\text{go})$ and $Q(v,\text{go})$ after the first episode.
(b) Give them after the second.
(c) State what value $Q(u,\text{go})$ is converging to, and how many episodes it takes to get within $0.5$ of it.
(d) State how the answer to (b) would change if the updates within an episode were applied in reverse order.

<details>
<summary>Solution</summary>

(a) *First transition:* target $= 0 + Q(v,\text{go}) = 0 + 0 = 0$, so $Q(u,\text{go}) \leftarrow 0 + 0.5(0-0) = \mathbf{0}$.

*Second transition:* terminal successor, target $= 4 + 0 = 4$, so $Q(v,\text{go}) \leftarrow 0 + 0.5(4-0) = \mathbf{2}$.

(b) *First transition:* target $= 0 + Q(v,\text{go}) = 2$, so $Q(u,\text{go}) \leftarrow 0 + 0.5(2 - 0) = \mathbf{1}$.

*Second transition:* target $= 4$, so $Q(v,\text{go}) \leftarrow 2 + 0.5(4-2) = \mathbf{3}$.

(c) The true values are $Q^*(v,\text{go}) = 4$ and $Q^*(u,\text{go}) = 0 + 4 = \mathbf{4}$, so $Q(u,\text{go}) \to 4$.

Each episode $Q(v)$ closes half its gap to $4$, while $Q(u)$ closes half its gap to the value $Q(v)$ held *before* that episode's own update — so $Q(u)$ lags one step behind. Running the recursion:

| episode | $Q(u,\text{go})$ | $Q(v,\text{go})$ |
|---|---|---|
| 1 | $0$ | $2$ |
| 2 | $1$ | $3$ |
| 3 | $2$ | $3.5$ |
| 4 | $2.75$ | $3.75$ |
| 5 | $3.25$ | $3.875$ |
| 6 | $\mathbf{3.5625}$ | $3.9375$ |

so $Q(u,\text{go})$ first comes within $0.5$ of $4$ at **episode 6**.

(d) Applying the second transition first would let the first transition bootstrap from the *already-updated* $Q(v,\text{go})$ within the same episode. Episode 1 would then give $Q(v,\text{go}) = 2$ and then $Q(u,\text{go}) \leftarrow 0 + 0.5(0 + 2 - 0) = 1$ — reaching in one episode what forward order took two to reach. Episode 2 would give $Q(v) = 3$ and $Q(u) = 1 + 0.5(3-1) = 2$.

**Reverse-order (backward) updating propagates reward one whole episode faster per state**, which is why offline implementations that can afford to store an episode often sweep it backwards — and why [Lesson 2.8](02-08-eligibility-traces-backward-view.md)'s eligibility traces, which achieve the same effect *online* without storing the episode, are worth the machinery.

</details>
