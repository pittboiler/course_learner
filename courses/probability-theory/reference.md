# Probability Theory · Reference Card

> Open book. This card is meant to be open while you work — including during
> quizzes. Nothing here is something you're expected to recall cold.

Probability *is* measure theory with total mass one. Everything below is that one
sentence unpacked: which sets you may measure (σ-algebras), which functions you
may ask about (random variables), what integration means (expectation), when you
may swap a limit with an integral (MCT / Fatou / DCT), the four different things
"$X_n\to X$" can mean, and finally what conditioning on partial information looks
like (projection) and what a fair game must do (martingales converge).

## Definitions

### Non-measurable set

A set to which **no** probability can be consistently assigned — not zero, not
anything. The Vitali set $V\subseteq[0,1)$ (one representative per rational-shift
class, built with the Axiom of Choice) has countably many disjoint translates
tiling the circle, and a constant repeated countably often can never sum to $1$.

*Introduced:* [1.1](lessons/01-01-why-measure-theory.md)

### σ-algebra

The disciplined collection of subsets you're allowed to call events: closed under
"not" and "countably many ors."

$$\Omega\in\mathcal F;\quad A\in\mathcal F\Rightarrow A^{c}\in\mathcal F;\quad A_1,A_2,\dots\in\mathcal F\Rightarrow\bigcup_{n}A_n\in\mathcal F$$

Countable intersections, set differences, and $\varnothing$ come free by De Morgan.
The pair $(\Omega,\mathcal F)$ is a **measurable space**.

*Introduced:* [1.2](lessons/01-02-sigma-algebras.md)

### Generated σ-algebra

The complete set of events you're *forced* to admit once you commit to measuring
the ones in $\mathcal C$ — defined abstractly, because there is no finite recipe.

$$\sigma(\mathcal C)=\bigcap\{\mathcal G:\mathcal G\text{ a }\sigma\text{-algebra on }\Omega,\ \mathcal C\subseteq\mathcal G\}$$

*Introduced:* [1.2](lessons/01-02-sigma-algebras.md)

### π-system

A collection closed under **finite intersection** — small enough to check by
hand, big enough to pin down everything it generates.

$$A,B\in\mathcal P\ \Rightarrow\ A\cap B\in\mathcal P$$

*Introduced:* [1.2](lessons/01-02-sigma-algebras.md)

### Measure

An "area" rule: the empty piece has size zero, and disjoint pieces add — even
countably many of them.

$$\mu(\varnothing)=0,\qquad \mu\Big(\bigsqcup_{n=1}^{\infty}A_n\Big)=\sum_{n=1}^{\infty}\mu(A_n)$$

A **probability measure** is the case $\mathbb P(\Omega)=1$; the triple
$(\Omega,\mathcal F,\mathbb P)$ is a **probability space**.

*Introduced:* [1.3](lessons/01-03-measures-probability-spaces.md)

### Outer measure

The cheapest total length of open intervals whose union still covers $A$. Defined
for **every** set — which is exactly why it is only sub-additive, not a measure.

$$\lambda^{*}(A)=\inf\Big\{\sum_{k}\ell(I_k)\ :\ A\subseteq\bigcup_k I_k,\ I_k\text{ open intervals}\Big\}$$

*Introduced:* [1.4](lessons/01-04-constructing-lebesgue-measure.md)

### Carathéodory's criterion

$A$ is measurable if it cuts every test set cleanly — probing $A$ with any $E$
loses no length. Keeping only these sets upgrades $\lambda^{*}$ to a real measure.

$$\lambda^{*}(E)=\lambda^{*}(E\cap A)+\lambda^{*}(E\cap A^{c})\qquad\text{for all }E\subseteq\mathbb R$$

*Introduced:* [1.4](lessons/01-04-constructing-lebesgue-measure.md)

### Almost surely

A property holds **a.s.** (equivalently a.e.) if the set where it fails has
probability zero. Two random variables equal a.s. are, for this course, the same.

*Introduced:* [1.4](lessons/01-04-constructing-lebesgue-measure.md)

### Random variable

A function whose value-questions are all events — the randomness is in which
$\omega$ nature draws, not in $X$.

$$X:\Omega\to\mathbb R\ \text{ with }\ X^{-1}(B)\in\mathcal F\ \text{ for every }B\in\mathcal B$$

**Reduction criterion:** it is enough that $\{X\le a\}\in\mathcal F$ for every real $a$.

*Introduced:* [2.1](lessons/02-01-random-variables-measurability.md)

### Distribution (law, pushforward)

The probability sand swept off $\Omega$ onto the real line. Once you have it, you
may forget $\Omega$ entirely.

$$\mu_X(B)=\mathbb P\big(X^{-1}(B)\big)=\mathbb P(X\in B),\qquad B\in\mathcal B$$

*Introduced:* [2.2](lessons/02-02-distributions-and-cdfs.md)

### Cumulative distribution function

The running weight of the sand pile, scanned left to right. It is nondecreasing,
**right**-continuous, and runs $0\to1$ — and those three properties characterize it.

$$F_X(x)=\mathbb P(X\le x)=\mu_X\big((-\infty,x]\big)$$

*Introduced:* [2.2](lessons/02-02-distributions-and-cdfs.md)

### Atom

A value the variable hits with positive probability — visible as a **jump** in $F$.

$$\mathbb P(X=x)=F(x)-F(x^{-})$$

*Introduced:* [2.2](lessons/02-02-distributions-and-cdfs.md)

### Density

A function you integrate to get the CDF. It exists **only** when $\mu_X$ puts no
mass on any Lebesgue-null set ($\mu_X\ll\lambda$); then $f=d\mu_X/d\lambda$.

$$F(x)=\int_{-\infty}^{x}f(t)\,dt,\qquad f\ge0,\ \int_{\mathbb R}f=1$$

*Introduced:* [2.2](lessons/02-02-distributions-and-cdfs.md)

### Simple function

A random variable with finitely many values — the atom the whole Lebesgue
integral is built from.

$$X=\sum_{i=1}^{n}a_i\,\mathbf 1_{A_i}\ (A_i\in\mathcal F\text{ disjoint}),\qquad \mathbb E[X]=\sum_{i=1}^{n}a_i\,\mathbb P(A_i)$$

*Introduced:* [2.3](lessons/02-03-lebesgue-integral-expectation.md)

### Expectation (the Lebesgue integral)

Slice the **range**, not the domain: for each height, measure the set where $X$
clears it. Built in three stages — simple, then nonnegative, then signed.

$$\mathbb E[X]=\sup\{\mathbb E[S]:S\text{ simple},\ 0\le S\le X\}\quad(X\ge0),\qquad \mathbb E[X]=\mathbb E[X^{+}]-\mathbb E[X^{-}]$$

*Introduced:* [2.3](lessons/02-03-lebesgue-integral-expectation.md)

### Integrable

$\mathbb E\lvert X\rvert<\infty$, i.e. **both** parts are finite. If both are
infinite, $\mathbb E[X]$ is *undefined*, never zero-by-symmetry.

*Introduced:* [2.3](lessons/02-03-lebesgue-integral-expectation.md)

### $L^p$ space

Random variables whose $p$-th moment is finite, with a.s.-equal variables
identified. $\lVert\cdot\rVert_p$ is a genuine norm (Minkowski), and $L^2$ is a
**Hilbert** space under $\langle X,Y\rangle=\mathbb E[XY]$ — complete, so
projections exist.

$$\lVert X\rVert_p=\big(\mathbb E\lvert X\rvert^{p}\big)^{1/p},\qquad L^p=\{X:\lVert X\rVert_p<\infty\}$$

*Introduced:* [2.5](lessons/02-05-lp-spaces-inequalities.md)

### Independence

Knowing one thing tells you nothing about the other — encoded as multiplication,
lifted from events to families to σ-algebras to random variables.

$$\mathbb P(A\cap B)=\mathbb P(A)\mathbb P(B);\qquad \mathbb P\Big(\bigcap_i G_i\Big)=\prod_i\mathbb P(G_i)\ \ (G_i\in\mathcal G_i)$$

$X\perp Y$ means $\sigma(X)\perp\sigma(Y)$, i.e.
$\mathbb P(X\in A,\,Y\in B)=\mathbb P(X\in A)\mathbb P(Y\in B)$ for all Borel $A,B$.

*Introduced:* [3.1](lessons/03-01-independence.md)

### Product measure

The unique measure on $\mathcal F_1\otimes\mathcal F_2$ that makes rectangles obey
"area $=$ width $\times$ height." Independence **is** the statement that the joint
law is a product.

$$(\mu_1\times\mu_2)(A\times B)=\mu_1(A)\,\mu_2(B);\qquad X\perp Y\iff\mu_{(X,Y)}=\mu_X\times\mu_Y$$

*Introduced:* [3.2](lessons/03-02-product-measures-fubini.md)

### Tail σ-algebra

The events still decidable after throwing away any finite prefix of the sequence
— "does $\sum X_n$ converge?", "does the average settle?"

$$\mathcal T=\bigcap_{n=1}^{\infty}\sigma(X_n,X_{n+1},\dots)$$

*Introduced:* [3.3](lessons/03-03-borel-cantelli-zero-one.md)

### Convolution

The law of a sum of **independent** variables: account for every split
$x+(z-x)=z$, weighted by how likely each piece is.

$$\mathbb P(X+Y\le z)=\int_{\mathbb R}F_X(z-y)\,d\mu_Y(y),\qquad f_{X+Y}(z)=\int_{\mathbb R}f_X(z-x)f_Y(x)\,dx$$

*Introduced:* [3.4](lessons/03-04-sums-of-random-variables.md)

### Characteristic function

Spin each outcome onto the unit circle at angle $tX$ and average the arrows — one
complex number per frequency. It **always exists** (the integrand has modulus 1),
determines the law uniquely, and turns independent sums into products.

$$\varphi_X(t)=\mathbb E\big[e^{itX}\big]=\int_{\mathbb R}e^{itx}\,d\mu_X(x)$$

*Introduced:* [4.3](lessons/04-03-characteristic-functions.md)

### Weak convergence

Probe each law with every bounded, continuous ("cliff-free") measurement and ask
whether the readouts settle. This *is* convergence in distribution.

$$\mu_n\Rightarrow\mu\iff \int f\,d\mu_n\to\int f\,d\mu\ \ \text{for every }f\in C_b(\mathbb R)$$

*Introduced:* [4.4](lessons/04-04-weak-convergence.md)

### Tightness

One fixed bounded window catches all but $\varepsilon$ of the mass, **uniformly in
$n$** — no mass sneaks off to infinity. It is exactly the compactness Prokhorov
needs to extract a limit law.

$$\forall\varepsilon>0\ \exists K\text{ compact}:\ \mu_n(K)\ge1-\varepsilon\ \text{ for all }n$$

*Introduced:* [4.4](lessons/04-04-weak-convergence.md)

### Conditional expectation

The $\mathcal G$-measurable random variable that shares $X$'s average over every
event the observer can resolve — the best guess of $X$ from what $\mathcal G$ sees.
Unique **up to a null set**.

$$Y\text{ is }\mathcal G\text{-measurable},\qquad \int_A Y\,d\mathbb P=\int_A X\,d\mathbb P\quad\text{for all }A\in\mathcal G \tag{$\star$}$$

For $X\in L^2$ it is the orthogonal projection onto $L^2(\mathcal G)$: the minimizer
of $\mathbb E[(X-Y)^2]$. Existence in general is Radon–Nikodym.

*Introduced:* [5.1](lessons/05-01-conditional-expectation.md)

### Filtration and adapted process

$\mathcal F_n$ is everything known by time $n$; information accumulates and is
never lost. A process is **adapted** if you can read off $X_n$ from $\mathcal F_n$.

$$\mathcal F_0\subseteq\mathcal F_1\subseteq\cdots\subseteq\mathcal F,\qquad X_n\ \text{is}\ \mathcal F_n\text{-measurable}$$

*Introduced:* [5.3](lessons/05-03-martingales.md)

### Martingale

A fair game: tomorrow's conditional forecast is exactly today's value. Adapted
and integrable are part of the definition, not fine print.

$$\mathbb E[X_{n+1}\mid\mathcal F_n]=X_n\quad(\text{sub: }\ge,\ \text{super: }\le)$$

*Introduced:* [5.3](lessons/05-03-martingales.md)

### Stopping time

A quitting rule you could execute live, with a stop button and no rewind.

$$T:\Omega\to\{0,1,2,\dots\}\cup\{\infty\},\qquad \{T\le n\}\in\mathcal F_n\ \text{ for every }n$$

*Introduced:* [5.4](lessons/05-04-stopping-times-optional-stopping.md)

### Upcrossing

One completed trip of the path from $\le a$ up to $\ge b$. $U_n[a,b]$ counts them
through time $n$ — and a fair game can only afford finitely many.

*Introduced:* [5.5](lessons/05-05-martingale-convergence.md)

### Uniform integrability

The hypothesis that upgrades a.s. convergence of a martingale to $L^1$
convergence — and hence makes the limit *close* the martingale,
$X_n=\mathbb E[X_\infty\mid\mathcal F_n]$. Without it, mass can escape and
$\mathbb E[X_n]\not\to\mathbb E[X_\infty]$.

*Introduced:* [5.5](lessons/05-05-martingale-convergence.md)

## Formulas and rules

### Consequences of the measure axioms

Everything here is two lines from countable additivity — no picture, no "obviously."

| Property | Statement |
|---|---|
| complement | $\mathbb P(A^{c})=1-\mathbb P(A)$ |
| monotonicity | $A\subseteq B\Rightarrow\mathbb P(A)\le\mathbb P(B)$, and $\mathbb P(B\setminus A)=\mathbb P(B)-\mathbb P(A)$ |
| inclusion–exclusion | $\mathbb P(A\cup B)=\mathbb P(A)+\mathbb P(B)-\mathbb P(A\cap B)$ |
| union bound (Boole) | $\mathbb P\big(\bigcup_n A_n\big)\le\sum_n\mathbb P(A_n)$ — **any** events, disjoint or not |
| continuity from below | $A_n\uparrow A\Rightarrow\mathbb P(A_n)\uparrow\mathbb P(A)$ |
| continuity from above | $A_n\downarrow A\Rightarrow\mathbb P(A_n)\downarrow\mathbb P(A)$ (needs some $\mathbb P(A_n)<\infty$ — automatic here) |

**Disjointification** is the trick behind the last three: set $B_1=A_1$,
$B_n=A_n\setminus(A_1\cup\cdots\cup A_{n-1})$, so the $B_n$ are disjoint with the
same running union.

*From* [1.3](lessons/01-03-measures-probability-spaces.md)

### Reading a CDF

| Want | Formula |
|---|---|
| interval mass | $\mathbb P(a<X\le b)=F(b)-F(a)$ |
| atom at $x$ | $\mathbb P(X=x)=F(x)-F(x^{-})$ |
| density where $F$ is smooth | $f(x)=F'(x)$ |
| uniqueness | $F_X=F_Y\Rightarrow\mu_X=\mu_Y$ (π–λ on the half-lines) |

*From* [2.2](lessons/02-02-distributions-and-cdfs.md)

### The distribution table

The course computes with these constantly and states them nowhere in one place.
Here $\varphi(t)=\mathbb E[e^{itX}]$; the course uses characteristic functions, not
MGFs, precisely because $\varphi$ always exists ([4.3](lessons/04-03-characteristic-functions.md)).

| Law | pmf / pdf | Support | Mean | Variance | $\varphi(t)$ | Models |
|---|---|---|---|---|---|---|
| point mass $\delta_c$ | $\mathbb P(X=c)=1$ | $\{c\}$ | $c$ | $0$ | $e^{itc}$ | a constant; the limit in a weak law |
| Bernoulli$(p)$ | $p^{k}(1-p)^{1-k}$ | $\{0,1\}$ | $p$ | $p(1-p)$ | $(1-p)+pe^{it}$ | one trial, one indicator |
| Rademacher | $\tfrac12$ each | $\{-1,+1\}$ | $0$ | $1$ | $\cos t$ | a fair coin step of a random walk |
| Binomial$(n,p)$ | $\binom{n}{k}p^{k}(1-p)^{n-k}$ | $\{0,\dots,n\}$ | $np$ | $np(1-p)$ | $\big((1-p)+pe^{it}\big)^{n}$ | successes in $n$ independent trials |
| Poisson$(\lambda)$ | $e^{-\lambda}\lambda^{k}/k!$ | $\{0,1,2,\dots\}$ | $\lambda$ | $\lambda$ | $\exp\!\big(\lambda(e^{it}-1)\big)$ | rare events at a fixed rate |
| Uniform$[a,b]$ | $\dfrac{1}{b-a}$ | $[a,b]$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^{2}}{12}$ | $\dfrac{e^{itb}-e^{ita}}{it(b-a)}$ | no location favored; Lebesgue measure normalized |
| Triangular on $[0,2]$ | $z$ on $[0,1]$, $2-z$ on $[1,2]$ | $[0,2]$ | $1$ | $\tfrac16$ | $\big(\frac{e^{it}-1}{it}\big)^{2}$ | the sum of two independent Uniform$[0,1]$ |
| Exponential$(\lambda)$ | $\lambda e^{-\lambda x}$ | $[0,\infty)$ | $1/\lambda$ | $1/\lambda^{2}$ | $\dfrac{\lambda}{\lambda-it}$ | memoryless waiting time |
| Gamma$(n,\lambda)$ (Erlang) | $\dfrac{\lambda^{n}x^{n-1}e^{-\lambda x}}{(n-1)!}$ | $[0,\infty)$ | $n/\lambda$ | $n/\lambda^{2}$ | $\Big(\dfrac{\lambda}{\lambda-it}\Big)^{n}$ | wait for the $n$-th arrival ($n$ exponentials) |
| Normal $N(\mu,\sigma^{2})$ | $\dfrac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^{2}/2\sigma^{2}}$ | $\mathbb R$ | $\mu$ | $\sigma^{2}$ | $\exp\!\big(i\mu t-\tfrac{\sigma^{2}t^{2}}{2}\big)$ | the CLT limit; sums of many small effects |
| $\chi^{2}_{1}$ | law of $Z^{2}$, $Z\sim N(0,1)$ | $[0,\infty)$ | $1$ | $2$ | $(1-2it)^{-1/2}$ | squared standardized error |
| Cauchy | $\dfrac{1}{\pi(1+x^{2})}$ | $\mathbb R$ | **none** | **none** | $e^{-\lvert t\rvert}$ | the standing counterexample: no LLN, no CLT |

**Stable under independent addition** (the sum stays in the family):
$N(\mu_1,\sigma_1^{2})+N(\mu_2,\sigma_2^{2})=N(\mu_1+\mu_2,\sigma_1^{2}+\sigma_2^{2})$;
$\text{Pois}(\lambda_1)+\text{Pois}(\lambda_2)=\text{Pois}(\lambda_1+\lambda_2)$;
$\text{Bin}(m,p)+\text{Bin}(n,p)=\text{Bin}(m+n,p)$; and Cauchy — whose stability is
exactly why its sample mean never concentrates. Almost nothing else is stable:
two Uniforms convolve to a **tent**, not a Uniform.

*From* [3.4](lessons/03-04-sums-of-random-variables.md) *and* [4.3](lessons/04-03-characteristic-functions.md)

### Computing an expectation

| Case | Formula |
|---|---|
| change of variables | $\mathbb E[g(X)]=\int_{\mathbb R}g\,d\mu_X$ — you never need $\Omega$ |
| density $f$ | $\mathbb E[g(X)]=\int_{\mathbb R}g(x)f(x)\,dx$ |
| discrete | $\mathbb E[g(X)]=\sum_i g(x_i)\,p_i$ |
| indicator | $\mathbb E[\mathbf 1_A]=\mathbb P(A)$ |
| layer cake ($X\ge0$) | $\mathbb E[X]=\int_0^{\infty}\mathbb P(X>t)\,dt$ |
| truncation | $\mathbb E[X]=\lim_n\mathbb E[\min(X,n)]$ for $X\ge0$ (MCT) |

Linearity, monotonicity, $\lvert\mathbb E[X]\rvert\le\mathbb E\lvert X\rvert$, and
"$X=Y$ a.s. $\Rightarrow\mathbb E[X]=\mathbb E[Y]$" hold throughout.

*From* [2.3](lessons/02-03-lebesgue-integral-expectation.md) *and* [3.2](lessons/03-02-product-measures-fubini.md)

### Swapping a limit with an expectation

The three licenses. Reach for them in this order.

| Theorem | Hypothesis | Conclusion |
|---|---|---|
| Monotone convergence (MCT) | $0\le X_n\uparrow X$ a.s. | $\mathbb E[X_n]\uparrow\mathbb E[X]$ (both sides may be $+\infty$) |
| Tonelli for sums | $Y_k\ge0$ | $\mathbb E\big[\sum_k Y_k\big]=\sum_k\mathbb E[Y_k]$, no check needed |
| Fatou | $X_n\ge0$ a.s. | $\mathbb E[\liminf_n X_n]\le\liminf_n\mathbb E[X_n]$ — **inequality only** |
| Dominated convergence (DCT) | $X_n\to X$ a.s. **and** one integrable $Y$ with $\lvert X_n\rvert\le Y$ for all $n$ | $\mathbb E[X_n]\to\mathbb E[X]$, and $\mathbb E\lvert X_n-X\rvert\to0$ |
| Bounded convergence | $X_n\to X$ a.s., $\lvert X_n\rvert\le c$ constant | $\mathbb E[X_n]\to\mathbb E[X]$ |

Fatou follows from MCT; DCT follows from Fatou. **The standing counterexample** is
the escaping spike $X_n=n\,\mathbf 1_{(0,1/n)}$ on $([0,1],\lambda)$: $X_n\to0$
pointwise but $\mathbb E[X_n]=1$ forever — not monotone, and
$\sup_n X_n\ge 1/x$ has no finite integral, so no dominator exists.

*From* [2.4](lessons/02-04-convergence-theorems.md)

### The inequality toolkit

Each one converts a moment you *have* into a bound on a quantity you *want* —
and each needs its own hypothesis.

| Inequality | Statement | Needs |
|---|---|---|
| Markov | $\mathbb P(X\ge a)\le\dfrac{\mathbb E[X]}{a}$ | $X\ge0$ and $a>0$ |
| Chebyshev | $\mathbb P(\lvert X-\mu\rvert\ge k)\le\dfrac{\operatorname{Var}(X)}{k^{2}}$ | finite variance, $k>0$ (it *is* Markov on $(X-\mu)^{2}$) |
| Jensen | $\varphi(\mathbb E[X])\le\mathbb E[\varphi(X)]$ | $\varphi$ **convex**, $\mathbb E[X]$ finite — concave flips it |
| Cauchy–Schwarz | $\mathbb E\lvert XY\rvert\le\lVert X\rVert_2\lVert Y\rVert_2$ | $X,Y\in L^{2}$ (the $p=q=2$ case of Hölder) |
| Hölder | $\mathbb E\lvert XY\rvert\le\lVert X\rVert_p\lVert Y\rVert_q$ | $p,q>1$ **conjugate**: $\tfrac1p+\tfrac1q=1$ |
| Minkowski | $\lVert X+Y\rVert_p\le\lVert X\rVert_p+\lVert Y\rVert_p$ | $1\le p<\infty$ — this is what makes $\lVert\cdot\rVert_p$ a norm |
| moment nesting | $r\le p\Rightarrow \lVert X\rVert_r\le\lVert X\rVert_p$, so $L^{p}\subseteq L^{r}$ | a **probability** space (total mass 1) — false on $\mathbb R$ with $\lambda$ |
| conditional Jensen | $\varphi(\mathbb E[X\mid\mathcal G])\le\mathbb E[\varphi(X)\mid\mathcal G]$ a.s. | $\varphi$ convex, $\varphi(X)$ integrable |

Two free consequences: $\operatorname{Var}(X)=\mathbb E[X^{2}]-\mathbb E[X]^{2}\ge0$
(Jensen with $\varphi(x)=x^{2}$), and $\lvert\rho\rvert\le1$ (Cauchy–Schwarz on the
centered variables). Higher moments give sharper tail bounds when they're finite.

*From* [2.5](lessons/02-05-lp-spaces-inequalities.md) *and* [5.2](lessons/05-02-conditional-expectation-properties.md)

### Independence: what it buys, and what it doesn't

| Claim | Status |
|---|---|
| $\mathbb P(A\cap B)=\mathbb P(A)\mathbb P(B)$ on generators (a π-system) | enough — independence on the whole σ-algebra follows |
| joint CDF factors, $F_{X,Y}=F_XF_Y$ | equivalent to $X\perp Y$ |
| joint density factors, $f_{X,Y}=f_Xf_Y$ a.e. | equivalent, when a density exists |
| $\mathbb E[XY]=\mathbb E[X]\mathbb E[Y]$, i.e. $\operatorname{Cov}=0$ | implied by independence, **not** equivalent to it |
| $\mathbb E[g(X)h(Y)]=\mathbb E[g(X)]\mathbb E[h(Y)]$ for all bounded Borel $g,h$ | equivalent to $X\perp Y$ |
| $g(X)\perp h(Y)$ for Borel $g,h$ | inherited — processing each side separately can't create dependence |
| pairwise independence | strictly weaker than mutual — every finite subfamily must factor |

*From* [3.1](lessons/03-01-independence.md)

### Fubini–Tonelli

Integrate by slices, in either order.

$$\int_{\Omega_1\times\Omega_2}f\,d(\mu_1\times\mu_2)=\int_{\Omega_1}\!\Big(\int_{\Omega_2}f\,d\mu_2\Big)d\mu_1=\int_{\Omega_2}\!\Big(\int_{\Omega_1}f\,d\mu_1\Big)d\mu_2$$

- **Tonelli** — legal whenever $f\ge0$ (and the spaces are σ-finite). No integrability check; the answer may be $+\infty$.
- **Fubini** — for signed $f$, legal only if $\int\lvert f\rvert<\infty$. You check that by running **Tonelli on $\lvert f\rvert$**, which is always allowed.

Skip the check and the two orders can genuinely disagree.

*From* [3.2](lessons/03-02-product-measures-fubini.md)

### Borel–Cantelli and the 0–1 law

One number, $\sum_n\mathbb P(A_n)$, decides an infinite fate.

| Result | Hypothesis | Conclusion |
|---|---|---|
| Borel–Cantelli I | $\sum_n\mathbb P(A_n)<\infty$ — **no independence needed** | $\mathbb P(A_n\text{ i.o.})=0$ |
| Borel–Cantelli II | $A_n$ **independent** and $\sum_n\mathbb P(A_n)=\infty$ | $\mathbb P(A_n\text{ i.o.})=1$ |
| Kolmogorov 0–1 law | $(X_n)$ independent, $A\in\mathcal T$ | $\mathbb P(A)\in\{0,1\}$ (from $p=p^{2}$) |

$\{A_n\text{ i.o.}\}=\limsup_n A_n$ (in infinitely many);
$\{A_n\text{ eventually}\}=\liminf_n A_n$ (in all but finitely many); the second
sits inside the first. The 0–1 law tells you the answer is extreme, never **which**
extreme — that's what BC II, a variance sum, or a law of large numbers is for.

*From* [3.3](lessons/03-03-borel-cantelli-zero-one.md)

### Sums of independent variables

$$\mathbb E[X+Y]=\mathbb E[X]+\mathbb E[Y]\quad\text{always};\qquad \operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)$$

Independence (or just zero correlation) kills the cross term, so for i.i.d.
$X_i$ with mean $\mu$ and variance $\sigma^{2}$:

$$\mathbb E[S_n]=n\mu,\quad \operatorname{Var}(S_n)=n\sigma^{2},\quad \operatorname{sd}(S_n)=\sigma\sqrt n;\qquad \mathbb E[\bar X_n]=\mu,\quad \operatorname{Var}(\bar X_n)=\frac{\sigma^{2}}{n}$$

That $\sqrt n$ is the whole module: noise grows slower than the sum, so $S_n/n$
becomes deterministic (LLN) while $S_n/\sqrt n$ stays random and Gaussian (CLT).

*From* [3.4](lessons/03-04-sums-of-random-variables.md)

### The four modes of convergence

Two strong modes (incomparable), one hub, one weak floor.

| Mode | Definition | Compares | Implies |
|---|---|---|---|
| almost surely, $\xrightarrow{a.s.}$ | $\mathbb P(X_n\to X)=1$ | the variables, pointwise off a null set | in probability |
| in $L^{p}$, $\xrightarrow{L^p}$ | $\mathbb E\lvert X_n-X\rvert^{p}\to0$ | the variables, in norm | in probability (Markov at level $\varepsilon^{p}$) |
| in probability, $\xrightarrow{P}$ | $\mathbb P(\lvert X_n-X\rvert>\varepsilon)\to0$ for every $\varepsilon>0$ | the variables, by polling | in distribution |
| in distribution, $\xrightarrow{d}$ | $F_{X_n}(x)\to F_X(x)$ at continuity points of $F_X$ | only the **laws** — no shared space needed | nothing further |

**No arrow reverses**, and the two strong modes don't imply each other:

| Blocked reverse | Counterexample on $([0,1],\lambda)$ |
|---|---|
| $P$ (and $L^{p}$) $\not\Rightarrow$ a.s. | the typewriter: $X_n=\mathbf 1_{[j/2^{k},(j+1)/2^{k}]}$ for $n=2^{k}+j$ — converges nowhere pointwise |
| a.s. (and $P$) $\not\Rightarrow$ $L^{p}$ | the escaping spike $X_n=n\,\mathbf 1_{(0,1/n)}$ — $\mathbb E\lvert X_n\rvert=1$ forever |
| $d\not\Rightarrow P$ | independent copies: i.i.d. fair signs, $\mathbb P(X_n\ne X)=\tfrac12$ always |

**Rescue facts** (use when the arrow you want is missing):

- **Subsequence principle.** $X_n\xrightarrow{P}X$ iff every subsequence has a further subsequence converging a.s.
- **In probability $+$ domination $\Rightarrow$ $L^{p}$.** If $\lvert X_n\rvert\le Y$ with $Y\in L^{p}$ — DCT in disguise.
- **In distribution to a *constant* $\Rightarrow$ in probability.** The one case where the weak floor lifts to the hub; this is how a characteristic-function limit becomes a weak law.

**Which theorem lives in which mode:** WLLN is $\xrightarrow{P}$ (and really $\xrightarrow{L^2}$ then Markov); SLLN is $\xrightarrow{a.s.}$; the CLT is $\xrightarrow{d}$ and nothing stronger; martingale convergence is $\xrightarrow{a.s.}$, upgraded to $L^{1}$ only under uniform integrability.

*From* [4.1](lessons/04-01-modes-of-convergence.md), [4.2](lessons/04-02-laws-of-large-numbers.md), [4.5](lessons/04-05-central-limit-theorem.md), [5.5](lessons/05-05-martingale-convergence.md)

### The limit theorems

| Theorem | Hypotheses | Conclusion |
|---|---|---|
| Weak LLN | i.i.d., $\sigma^{2}<\infty$ (finite mean alone suffices, harder proof) | $\bar X_n\xrightarrow{P}\mu$; Chebyshev gives $\mathbb P(\lvert\bar X_n-\mu\rvert\ge\varepsilon)\le\sigma^{2}/(n\varepsilon^{2})$ |
| Strong LLN (Kolmogorov) | i.i.d., $\mathbb E\lvert X_1\rvert<\infty$ | $\bar X_n\xrightarrow{a.s.}\mu$ |
| CLT (i.i.d.) | i.i.d., $\sigma^{2}\in(0,\infty)$ | $Z_n=\dfrac{S_n-n\mu}{\sigma\sqrt n}\xrightarrow{d}N(0,1)$ |
| Lindeberg–Feller | independent, not identical, no single term dominates | same normal limit |
| Berry–Esseen | $\mathbb E\lvert X_1\rvert^{3}<\infty$ | $\sup_z\lvert\mathbb P(Z_n\le z)-\Phi(z)\rvert=O(1/\sqrt n)$ |

**The CLT proof in four moves:** standardize; expand
$\varphi(t)=1-\tfrac{t^{2}}{2}+o(t^{2})$ (the *only* place finite variance is used);
multiply, $\varphi_{Z_n}(t)=[\varphi(t/\sqrt n)]^{n}$; take the limit via
$(1+c_n/n)^{n}\to e^{c}$ to get $e^{-t^{2}/2}$, then invoke Lévy continuity.

*From* [4.2](lessons/04-02-laws-of-large-numbers.md) *and* [4.5](lessons/04-05-central-limit-theorem.md)

### Characteristic-function rules

| Rule | Statement |
|---|---|
| normalization | $\varphi_X(0)=1$ and $\lvert\varphi_X(t)\rvert\le1$ for all $t$ |
| conjugate symmetry | $\varphi_X(-t)=\overline{\varphi_X(t)}$ |
| shift and scale | $\varphi_{aX+b}(t)=e^{itb}\varphi_X(at)$ |
| smoothness | $\varphi_X$ is uniformly continuous on $\mathbb R$ (DCT with dominator 2) |
| independence | $X\perp Y\Rightarrow\varphi_{X+Y}=\varphi_X\varphi_Y$; i.i.d. $\Rightarrow\varphi_{S_n}=\varphi^{n}$ |
| moments | $\mathbb E\lvert X\rvert^{k}<\infty\Rightarrow\varphi^{(k)}(0)=i^{k}\mathbb E[X^{k}]$ |
| second-order expansion | $\varphi_X(t)=1+it\,\mathbb E[X]-\tfrac{t^{2}}{2}\mathbb E[X^{2}]+o(t^{2})$ |
| uniqueness | $\varphi_X=\varphi_Y\iff\mu_X=\mu_Y$ |
| inversion (when $\varphi_X\in L^{1}$) | $f_X(x)=\dfrac{1}{2\pi}\displaystyle\int_{-\infty}^{\infty}e^{-itx}\varphi_X(t)\,dt$ |
| Lévy continuity | $X_n\xrightarrow{d}X\iff\varphi_{X_n}(t)\to\varphi_X(t)$ for every $t$ (limit continuous at $0$) |

*From* [4.3](lessons/04-03-characteristic-functions.md)

### Portmanteau — five faces of $\mu_n\Rightarrow\mu$

All equivalent:

1. $\int f\,d\mu_n\to\int f\,d\mu$ for every $f\in C_b(\mathbb R)$;
2. $\limsup_n\mu_n(C)\le\mu(C)$ for every **closed** $C$;
3. $\liminf_n\mu_n(U)\ge\mu(U)$ for every **open** $U$;
4. $\mu_n(A)\to\mu(A)$ for every $\mu$-**continuity set** ($\mu(\partial A)=0$);
5. $F_n(x)\to F(x)$ at every continuity point of $F$.

**Continuous mapping:** $X_n\xrightarrow{d}X$ and $g$ continuous off a set of
$\mu_X$-measure zero $\Rightarrow g(X_n)\xrightarrow{d}g(X)$ (so
$X_n\xrightarrow{d}N(0,1)$ gives $X_n^{2}\xrightarrow{d}\chi^{2}_{1}$).
**Prokhorov:** tight $\iff$ relatively compact for weak convergence.
**Skorokhod representation** (named): weak convergence can be realized as a.s.
convergence on one space.

*From* [4.4](lessons/04-04-weak-convergence.md)

### Conditional expectation — the working rulebook

You almost never return to $(\star)$; these seven are the daily tools.

| Rule | Statement |
|---|---|
| linearity | $\mathbb E[aX+bY\mid\mathcal G]=a\,\mathbb E[X\mid\mathcal G]+b\,\mathbb E[Y\mid\mathcal G]$ |
| monotonicity | $X\le Y\Rightarrow\mathbb E[X\mid\mathcal G]\le\mathbb E[Y\mid\mathcal G]$ a.s. |
| total expectation | $\mathbb E\big[\mathbb E[X\mid\mathcal G]\big]=\mathbb E[X]$ |
| tower ($\mathcal G_1\subseteq\mathcal G_2$) | $\mathbb E\big[\mathbb E[X\mid\mathcal G_2]\mid\mathcal G_1\big]=\mathbb E[X\mid\mathcal G_1]$ — the **coarser** σ-algebra wins, either nesting order |
| pull-out | $Z$ is $\mathcal G$-measurable $\Rightarrow\mathbb E[ZX\mid\mathcal G]=Z\,\mathbb E[X\mid\mathcal G]$ |
| independence drops out | $X\perp\mathcal G\Rightarrow\mathbb E[X\mid\mathcal G]=\mathbb E[X]$ |
| already known | $X$ is $\mathcal G$-measurable $\Rightarrow\mathbb E[X\mid\mathcal G]=X$ |

Every identity holds **almost surely**. Two standard corollaries:

$$\text{Wald: }\ \mathbb E\Big[\sum_{i=1}^{N}X_i\Big]=\mathbb E[N]\,\mathbb E[X_1]\quad(N\perp(X_i));\qquad \operatorname{Var}(X)=\mathbb E\big[\operatorname{Var}(X\mid\mathcal G)\big]+\operatorname{Var}\big(\mathbb E[X\mid\mathcal G]\big)$$

The second is the law of total variance — the probabilist's ANOVA. On a countable
partition $\{B_i\}$, $\mathbb E[X\mid\mathcal G]=\sum_i\frac{\mathbb E[X\mathbf 1_{B_i}]}{\mathbb P(B_i)}\mathbf 1_{B_i}$: the block average.

*From* [5.1](lessons/05-01-conditional-expectation.md) *and* [5.2](lessons/05-02-conditional-expectation-properties.md)

### Martingales: the standard examples

| Process | Why it's a martingale |
|---|---|
| $S_n=\sum_{i\le n}\xi_i$, $\xi_i$ independent mean zero | pull out $S_n$, drop the independent $\xi_{n+1}$ |
| $S_n^{2}-n\sigma^{2}$ (same $\xi_i$, variance $\sigma^{2}$) | the compensated square — subtracting the drift $n\sigma^{2}$ |
| $M_n=\prod_{i\le n}Y_i$, $Y_i>0$ independent with $\mathbb E[Y_i]=1$ | mean-one multiplicative increments |
| $L_n=\prod_{i\le n}q(\xi_i)/p(\xi_i)$ (likelihood ratio) | each factor has mean $1$ under $p$ — a product martingale |
| $X_n=\mathbb E[X\mid\mathcal F_n]$ (Doob–Lévy) | one line of the tower property |
| $(q/p)^{S_n}$ for a $p$-biased $\pm1$ walk | $p\,r+q\,r^{-1}=1$ at $r=q/p$ |

**Constant expectation:** $\mathbb E[X_n]=\mathbb E[X_0]$ (sub: rises; super: falls).
**Convexity:** $\varphi$ convex and $(X_n)$ a martingale $\Rightarrow(\varphi(X_n))$ is a
**sub**martingale — so $X_n^{2}$ and $\lvert X_n\rvert$ are submartingales.

*From* [5.3](lessons/05-03-martingales.md)

### Optional stopping and gambler's ruin

A stopped martingale is always a martingale, so $\mathbb E[X_{T\wedge n}]=\mathbb E[X_0]$
for every **finite** $n$, free. Getting to $\mathbb E[X_T]=\mathbb E[X_0]$ needs a
limit-swap, i.e. one of:

| Clause | Hypothesis | Why it works |
|---|---|---|
| (i) | $T\le N$ for a constant $N$ | there is no limit to take |
| (ii) | $T<\infty$ a.s. **and** $\lvert X_{T\wedge n}\rvert\le M$ for all $n$ | bounded convergence |
| (iii) | $\mathbb E[T]<\infty$ **and** $\lvert X_n-X_{n-1}\rvert\le c$ | dominated convergence, dominator $\lvert X_0\rvert+cT$ |

For a supermartingale the same clauses give $\mathbb E[X_T]\le\mathbb E[X_0]$.
**Symmetric gambler's ruin** — walk from $x$, absorbing barriers $0$ and $N$:

$$\mathbb P(\text{hit }N\text{ first})=\frac{x}{N},\qquad \mathbb E[T]=x(N-x)$$

(first from the martingale $S_n$, second from $S_n^{2}-n$). Biased walk with
$r=q/p$: $\ \mathbb P(\text{ruin})=\dfrac{r^{N}-r^{x}}{r^{N}-1}$. **Wald's identity**
$\mathbb E[S_T]=\mu\,\mathbb E[T]$ is clause (iii) applied to $S_n-n\mu$.

*From* [5.4](lessons/05-04-stopping-times-optional-stopping.md)

### Martingale convergence

| Result | Hypothesis | Conclusion |
|---|---|---|
| Doob upcrossing inequality | $(X_n)$ a supermartingale | $(b-a)\,\mathbb E\big[U_n[a,b]\big]\le\mathbb E\big[(X_n-a)^{-}\big]$ |
| Martingale convergence theorem | $\sup_n\mathbb E\lvert X_n\rvert<\infty$ ($L^{1}$-bounded super/martingale) | $X_n\to X_\infty$ **a.s.**, $\mathbb E\lvert X_\infty\rvert<\infty$ |

## Pitfalls

### Sets, σ-algebras, and measure

- "$V$ has no probability" does **not** mean $\mathbb P(V)=0$ — measure zero is a harmless *value*; non-measurable means no consistent value exists. *([1.1](lessons/01-01-why-measure-theory.md), [1.4](lessons/01-04-constructing-lebesgue-measure.md))*
- **Finite** additivity does not create the Vitali contradiction — a finitely-additive translation-invariant $\mathbb P$ on all subsets can exist. Countable additivity is the axiom under attack, and the one worth protecting. *([1.1](lessons/01-01-why-measure-theory.md), [1.3](lessons/01-03-measures-probability-spaces.md))*
- The "σ" means **countable** unions, deliberately — arbitrary unions may escape $\mathcal F$, and that's exactly what blocks the pathology (and what separates a σ-algebra from a topology). *([1.2](lessons/01-02-sigma-algebras.md))*
- $\sigma(\mathcal C)$ is not "throw in complements and unions once" — there's no finite recipe, which is why it's defined as an intersection of all containing σ-algebras. *([1.2](lessons/01-02-sigma-algebras.md))*
- Keep the levels straight: $\omega\in\Omega$ is an outcome, $A\in\mathcal F$ is an event (a *set*), $\mathcal F\subseteq2^{\Omega}$ is the event system. *([1.2](lessons/01-02-sigma-algebras.md))*
- $\mathcal F_1\cap\mathcal F_2$ is a σ-algebra; $\mathcal F_1\cup\mathcal F_2$ generally is **not** — wrap it in $\sigma(\cdot)$. *([1.2](lessons/01-02-sigma-algebras.md))*
- Additivity is for **disjoint** events. $\mathbb P(A\cup B)=\mathbb P(A)+\mathbb P(B)$ is false when they overlap; you owe inclusion–exclusion, or settle for the union-bound inequality. *([1.3](lessons/01-03-measures-probability-spaces.md))*
- Continuity **from above** secretly needs some $\mathbb P(A_n)<\infty$ — automatic for probabilities, but it fails for general measures ($\lambda([n,\infty))=\infty$ for all $n$, intersection empty). *([1.3](lessons/01-03-measures-probability-spaces.md))*
- Outer measure is defined everywhere but is only **sub**-additive off $\mathcal L$; measure zero is not "empty" (the Cantor set is uncountable and null); and don't collapse $\mathcal B\subsetneq\mathcal L\subsetneq2^{\mathbb R}$. *([1.4](lessons/01-04-constructing-lebesgue-measure.md))*

### Random variables and their laws

- Measurability is a **relationship**, not a solo trait — always ask "measurable with respect to which $\mathcal F$?" And it's the **preimage** that must be an event; the forward image need not be Borel. *([2.1](lessons/02-01-random-variables-measurability.md))*
- You never check all Borel $B$: the half-lines $\{X\le a\}$ generate $\mathcal B$, so checking generators is the entire technique. *([2.1](lessons/02-01-random-variables-measurability.md))*
- Pointwise limits destroy continuity but **never** measurability — $\sup$, $\inf$, $\limsup$, $\liminf$, $\lim$ of random variables are random variables. That closure is what lets the convergence theorems speak. *([2.1](lessons/02-01-random-variables-measurability.md))*
- $F$ is **right**-continuous, not left — the "$\le$" puts the value at a jump on the *upper* level, and the left limit $F(x^{-})$ is what gives the atom. *([2.2](lessons/02-02-distributions-and-cdfs.md))*
- Not every random variable has a density: discrete ones have atoms, and the Cantor distribution has a continuous $F$ with **no** density (its mass hides on a null set). Continuity of $F$ is necessary, not sufficient. *([2.2](lessons/02-02-distributions-and-cdfs.md))*
- $X\stackrel{d}{=}Y$ is much weaker than $X=Y$ — they needn't even share a sample space, which is why every limit theorem here is a statement about laws. *([2.2](lessons/02-02-distributions-and-cdfs.md))*

### Expectation and integration

- If $\mathbb E[X^{+}]=\mathbb E[X^{-}]=\infty$ then $\mathbb E[X]$ is **undefined**, not zero by symmetry. Integrability means $\mathbb E\lvert X\rvert<\infty$. *([2.3](lessons/02-03-lebesgue-integral-expectation.md))*
- $\mathbb E[X]=\int xf\,dx$ is a *consequence* (change of variables in the density case), not the definition — the definition is the three-stage sup construction. *([2.3](lessons/02-03-lebesgue-integral-expectation.md))*
- Changing $X$ on a null set changes no expectation — which is exactly why the everywhere-discontinuous Dirichlet function still integrates to $0$. *([2.3](lessons/02-03-lebesgue-integral-expectation.md))*
- MCT needs **nonnegative and increasing**; Fatou gives an **inequality** only and must never be read backwards; DCT needs *one single* dominator for all $n$, not per-term integrability. *([2.4](lessons/02-04-convergence-theorems.md))*
- You never need uniform convergence here — a.s. plus monotonicity or domination is enough, and that loosening is the whole point of building the Lebesgue integral. *([2.4](lessons/02-04-convergence-theorems.md))*
- For a **signed** integrand, confirm $\int\lvert f\rvert<\infty$ (via Tonelli on $\lvert f\rvert$) before swapping the order of integration — the two orders can genuinely disagree. *([3.2](lessons/03-02-product-measures-fubini.md))*
- The product σ-algebra is *generated by* rectangles, not equal to them; it contains diagonals, disks, everything Borel in the plane. *([3.2](lessons/03-02-product-measures-fubini.md))*

### Inequalities and $L^p$

- $L^{p}\subseteq L^{r}$ for $r\le p$ holds **only** on a finite-measure space — on $\mathbb R$ with Lebesgue measure it fails ($1/x$ on $[1,\infty)$ is in $L^{2}$, not $L^{1}$). *([2.5](lessons/02-05-lp-spaces-inequalities.md))*
- Jensen needs $\varphi$ **convex**; concave flips it ($\mathbb E[\log X]\le\log\mathbb E[X]$). Same warning for the conditional version, where the flip breaks the submartingale argument downstream. *([2.5](lessons/02-05-lp-spaces-inequalities.md), [5.2](lessons/05-02-conditional-expectation-properties.md))*
- Hölder's exponents must be **conjugate**, $\tfrac1p+\tfrac1q=1$; Cauchy–Schwarz is only the symmetric case. *([2.5](lessons/02-05-lp-spaces-inequalities.md))*
- Chebyshev is a *guarantee*, not an estimate — it's typically loose (0.73 vs. a true 0.33 on a die roll). Use it for proofs, not for accurate numbers. *([2.5](lessons/02-05-lp-spaces-inequalities.md))*

### Independence and sums

- **Zero covariance is not independence.** $X$ uniform on $\{-1,0,1\}$ and $Y=X^{2}$ are uncorrelated yet functionally dependent. (Jointly Gaussian is the one place they coincide.) *([3.1](lessons/03-01-independence.md))*
- **Pairwise is not mutual** — the coin/XOR triple passes every pair and fails as a trio. Every finite subcollection must factor. *([3.1](lessons/03-01-independence.md))*
- Independence is a property of the **joint** law; identical marginals can hide wildly different dependence. A non-rectangular support already rules it out. *([3.1](lessons/03-01-independence.md), [3.2](lessons/03-02-product-measures-fubini.md))*
- Means always add; **variances only add without a covariance term** under independence (or zero correlation). $\operatorname{Var}(X+(-X))=0$, not $2\operatorname{Var}(X)$. *([3.4](lessons/03-04-sums-of-random-variables.md))*
- $\operatorname{sd}(S_n)=\sigma\sqrt n$ — the sum spreads like $\sqrt n$, *slower* than its mean $n\mu$ grows. That gap is the whole reason averaging works. *([3.4](lessons/03-04-sums-of-random-variables.md))*
- Convolution needs independence: for dependent variables the law of $X+Y$ requires the full joint law, not $f_X$ and $f_Y$. *([3.4](lessons/03-04-sums-of-random-variables.md))*
- Stability under addition is the exception, not the rule — two Uniforms give a tent. *([3.4](lessons/03-04-sums-of-random-variables.md))*

### Infinitely often, and limits

- Borel–Cantelli **I needs no independence**; only BC II does. And without independence a divergent sum buys nothing: $A_n=B$ for all $n$ gives $\mathbb P(A_n\text{ i.o.})=\mathbb P(B)$, strictly between 0 and 1. *([3.3](lessons/03-03-borel-cantelli-zero-one.md))*
- The 0–1 law says the answer is *extreme*, not *which* extreme — deciding which is always the real work. *([3.3](lessons/03-03-borel-cantelli-zero-one.md))*
- $\limsup A_n$ (i.o.) and $\liminf A_n$ (eventually always) are different events: "heads infinitely often" is certain, "heads eventually always" has probability zero. *([3.3](lessons/03-03-borel-cantelli-zero-one.md))*
- $X_n\xrightarrow{d}X$ says nothing about the values tracking each other — only the histograms. With a non-constant limit the joint behavior is completely unconstrained. *([4.1](lessons/04-01-modes-of-convergence.md), [4.4](lessons/04-04-weak-convergence.md))*
- a.s. and $L^{p}$ are **incomparable** — neither implies the other; both only imply "in probability." *([4.1](lessons/04-01-modes-of-convergence.md))*
- Test functions for weak convergence must be **continuous**, not merely bounded: indicators have cliffs and genuinely fail ($\delta_{1/n}\Rightarrow\delta_0$ but $\mu_n(\{0\})=0\not\to1$). CDF convergence is required only at continuity points. *([4.4](lessons/04-04-weak-convergence.md))*
- Without tightness a sequence of laws may have **no** weakly convergent subsequence — $\mu_n=\delta_n$ leaks all its mass to infinity. *([4.4](lessons/04-04-weak-convergence.md))*

### The two crown theorems

- Weak vs. strong law is a real gap, not a restatement: in probability at each snapshot vs. the whole path settling. Don't quote one as the other. *([4.2](lessons/04-02-laws-of-large-numbers.md))*
- **No mean, no law.** The Cauchy average is Cauchy for every $n$ and never concentrates. Finite variance is a crutch for the *easy* WLLN proof; the SLLN needs only $\mathbb E\lvert X_1\rvert<\infty$. *([4.2](lessons/04-02-laws-of-large-numbers.md))*
- It's the **average** that converges, not the sum: $S_n$ itself diverges or wanders like $\pm\sqrt n$. *([4.2](lessons/04-02-laws-of-large-numbers.md))*
- The CLT is convergence **in distribution only** — $Z_n$ rattles around $N(0,1)$ forever and converges a.s. to nothing. *([4.5](lessons/04-05-central-limit-theorem.md))*
- The $\sqrt n$ normalization is not negotiable, and finite nonzero variance is required — heavy tails converge to non-normal **stable laws** instead. *([4.5](lessons/04-05-central-limit-theorem.md))*
- Use $\varphi$, not the MGF: $\varphi$ always exists (Cauchy has no MGF but $\varphi(t)=e^{-\lvert t\rvert}$ is fine). Differentiability of $\varphi$ at $0$ is *equivalent* to existence of moments, not automatic. And Lévy's theorem delivers $\xrightarrow{d}$ only. *([4.3](lessons/04-03-characteristic-functions.md))*

### Conditioning and martingales

- $\mathbb E[X\mid\mathcal G]$ is a **random variable**, not a number — conditioning on an *event* gives a number, on a *σ-algebra* a function of where you are. And every identity involving it is an "a.s." statement. *([5.1](lessons/05-01-conditional-expectation.md), [5.2](lessons/05-02-conditional-expectation-properties.md))*
- The projection picture needs $X\in L^{2}$; the definition and existence hold for all of $L^{1}$ via Radon–Nikodym. Partial averaging is the load-bearing definition. *([5.1](lessons/05-01-conditional-expectation.md))*
- "Conditioning on $Y$" means conditioning on $\sigma(Y)$ — the *information* in $Y$, not its value. *([5.1](lessons/05-01-conditional-expectation.md))*
- The tower collapses to the **coarser** σ-algebra regardless of nesting order in the notation. *([5.2](lessons/05-02-conditional-expectation-properties.md))*
- Pull-out needs $Z$ to be $\mathcal G$-**measurable**; independence is the *opposite* hypothesis and does something else entirely. Confusing the two is the module's most common error. *([5.2](lessons/05-02-conditional-expectation-properties.md))*
- $\mathbb E[X_{n+1}]=\mathbb E[X_n]$ is far weaker than the martingale property, which is **conditional** and must hold path-by-path. *([5.3](lessons/05-03-martingales.md))*
- The prefix lies: a **super**martingale tends to **decrease**. Sub $\Rightarrow$ up, super $\Rightarrow$ down. *([5.3](lessons/05-03-martingales.md))*
- A rule that peeks ahead ("sell at the maximum", "quit the step before busting") is **not** a stopping time, and a stopping time can be infinite with positive probability. *([5.4](lessons/05-04-stopping-times-optional-stopping.md))*
- $\mathbb E[X_T]=\mathbb E[X_0]$ is **false in general** — the stopped process gives it only at finite $n$, and one of clauses (i)–(iii) must justify the limit. The doubling scheme is the standing counterexample: it "wins" only on unbounded capital and unbounded time. *([5.4](lessons/05-04-stopping-times-optional-stopping.md), [5.3](lessons/05-03-martingales.md))*
- $L^{1}$-boundedness gives **almost-sure** convergence only; $\mathbb E[X_n]\to\mathbb E[X_\infty]$ needs uniform integrability (the product martingale with $\mathbb E[M_n]=1$ converging a.s. to $0$ is the counterexample). And the limit may be degenerate. *([5.5](lessons/05-05-martingale-convergence.md))*
- For supermartingales the useful one-sided bound is bounded **below** (e.g. nonnegative) — bounded above is not enough. *([5.5](lessons/05-05-martingale-convergence.md))*
